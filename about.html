Crafting User-Centric Web Solutions

Hello! I am Nirnay Mondal, a web developer currently completing the ApexPlanet 45-Day Web Development Internship. My core focus is on mastering foundational web technologies without relying immediately on heavy frameworks, ensuring an in-depth understanding of browser engines, DOM manipulation, responsive layouts, and clean coding standards.

Internship Objective: To build scalable, accessible, and performant web applications using clean HTML5, modular CSS3 (CSS Custom Properties, Flexbox, and CSS Grid), and pure Vanilla JavaScript with browser APIs like localStorage and the Fetch API.

Development Interests & Philosophy

I believe great software emerges at the intersection of robust code architecture and deliberate UI/UX design. My daily development workflow prioritizes:

  • ✓ Semantic & Accessible HTML: Creating inclusive web pages structured for screen readers, keyboard navigation, and SEO.
  • ✓ Modern Responsive CSS: Designing layout systems that look impeccable on every device from 375px smartphones to ultra-wide displays.
  • ✓ Modular JavaScript: Writing maintainable, event-driven, and bug-free JavaScript adhering to ES6+ best practices.
  • ✓ Client-side Persistence: Utilizing the browser's localStorage API for reliable, offline-capable state synchronization.
